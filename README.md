# 🚀 Fresh Tech Cadets | Zero to One in Web Dev & AI/ML

> *"Every expert was once a beginner. We are here to learn, build, and grow together from Day 1."*

Welcome to the official repository of our fresh tech team! We are a group of absolute beginners with zero prior tech background, driven by pure curiosity and a shared ambition to master **Web Development** and **AI/ML**.

## 🎯 Our Mission
We believe in building in public, peer learning, and hands-on practice. Our goal is to transform from absolute scratch to building real-world, production-ready AI and Web applications.

- **Phase 1:** Master the Basics (Python, HTML, CSS, Git & GitHub)
- **Phase 2:** Build Modern Web Interfaces & Full-Stack Apps
- **Phase 3:** Dive Deep into AI/ML, Prompt Engineering & LLM Workflows
- **Phase 4:** Collaborate on Real-World Team Projects & Open Source

## 📅 Our Team Rules & Culture
1. **Consistency Over Intensity:** Small daily code commits matter more than weekend marathons.
2. **No Dumb Questions:** Every error is a learning opportunity.
3. **Proof of Work:** Everything we code goes live on GitHub.
4. **Peer Support:** Help each other debug, review code, and grow together.
